## ✅ Недавно сделано

**v1.8**
- Статистика в Обзоре: «освобождено всего» + график по неделям
- Умные советы: кэши разработчика, пылящиеся приложения, сироты, предупреждение о кончающемся месте
- Инкрементальное сканирование — пересканируются только изменившиеся папки
- Энергосбережение меню-бара (анимация подстраивается под нагрузку)
- Xcode: симуляторы и DeviceSupport; пакетные менеджеры: Maven, SwiftPM, Cargo, Go
- «Сироты»: Containers, Group Containers, Application Scripts, LaunchAgents

**v1.6–1.7**
- Оптимизация сканирования (свой du, ленивые списки, кэш сканирования)
- Внешний IP + флаг страны (видно включённый VPN)
- Давно не используемые приложения, тема «Авто», правый клик по файлам

## ❄️ Заморожено (с причиной)

- **Виджет WidgetKit на рабочий стол** — попробовали в цикле 1.8, не взлетело:
  система требует sandboxed-расширение с настоящим Apple Team ID, а на macOS 26
  виджет не регистрируется, если родительское приложение не в sandbox
  (подтверждённое ограничение). Песочница несовместима с чистильщиком —
  ему нужно удалять файлы по всему диску. Вернуться при изменении политики Apple.
- **Developer ID + нотаризация** — нужен платный аккаунт Apple Developer ($99/год).
  Снимет предупреждение Gatekeeper при установке.
- **Официальный homebrew-cask** — нужно ~30⭐ на GitHub.
